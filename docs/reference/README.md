# 参考：tqserve CLI 输出

本目录保存 tqLLM 1.6.0 引擎二进制 `tqserve` 的帮助输出，作为参数映射的原始依据：

- `tqserve_help.txt` — `tqserve --help`
- `tqserve_list_flags.txt` — `tqserve --list-flags`（环境变量与诊断开关）
- `tqserve_list_kv.txt` — `tqserve --list-kv`（KV 存储格式）

来源：[turbo-tan/tqllm](https://github.com/turbo-tan/tqllm)，Apache-2.0。
这些是 CLI 帮助文本（非引擎源码或二进制）；引擎本体请通过官方渠道安装，本仓库不分发。
