# tqLLM Control Center｜界面规格 v2.1

**设计状态：** 可交互的离线 HTML 原型，非已连接 tqLLM 的应用。

## 交付文件

- `tqllm_control_center.html`：完整离线交互界面，macOS 浏览器双击即可打开。
- `tqllm_control_center_ui_spec.md`：本设计说明。

## 视觉原则

- 背景：浅灰 `#F3F4F5`；卡片：白色 `#FFFFFF`；描边：`#E7E9EC`。
- 样式：圆角、细描边、简洁线性图标、深灰文字、克制的绿/琥珀状态提示。
- 一级页面：总览、功能入口；二级页面：针对每个功能的详细配置。
- **保留原型左下角** `tqLLM Control Center · Interface Design v2`。
- **保留原型右下角** `浅灰背景 · 白色卡片 · 原型`。

## 重要交互调整

1. **首页顶部改为运行状态卡片**，参考 Splash 的 Activity 信息密度，而非重复介绍文案：
   - Answering / 持续生成 Tokens/s
   - Reading Prompts / Prefill Tokens/s
   - First Token / 首 Token 延迟
   - Context Limit / 上下文上限
   - Memory / 内存占用
   - 模型名称、版本、芯片与运行状态
2. **启动／停止开关移到顶部全局工具栏**，不必先进入“服务控制”。“服务控制”详情保留路径、自动启动、启动/重启策略。
3. 首页保留十个极简功能入口，每个进入独立设置页。
4. 交互原型明确区分演示状态、历史截图和真实连接；不得把原型点击视作实际模型进程操作。

## 运行版接入要求

- 本机环境记录：Mac mini Apple M5 Pro、48 GB、tqLLM 1.6.0。
- 历史 CLI 路径：`/Users/xingbin/.tqllm/venv/bin/tqllm`（尚未在本次环境核验）。
- 用户模型目录：`/Volumes/移动硬盘/AI-Models/Qwen3.8-27B-QSA`。
- 应优先核验 CLI `--help`、运行参数、API 可用接口、进程归属、QSA 文件和日志格式。
- 运行中不可变的参数，必须显示“需要重启”并落实安全重启。
- 停止操作不得误杀其他程序启动的服务。
- 进行速度对比时固定同一模型/量化/Prompt/输出长度和采样条件，分别核对 QSA 是否实际触发。
- 真正的密钥存储应采用 macOS Keychain 等安全方式，不使用明文配置文件。

## 原型的边界

- 顶栏开关、环境扫描、连接测试和“重启”均为**交互演示**，不改变本机进程。
- 导出 JSON 为配置草案；JSON 不包含 API Key。
- 页面配置可以保存在浏览器本地存储，但不会写入 tqLLM 真实配置。
- 性能页面只展示用户已提供的历史数据，没有虚构实时监控。
